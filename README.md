# 8B: free website templates and an AI website builder

[8B](https://8b.com/) is an AI website builder. Here we publish free website templates made for AI coding agents, and the 8B plugins for Claude, Cursor, Codex and other agents.

## Free HTML website templates

20 one-page website templates, each one HTML file with GSAP scroll animations. MIT license, no build step, no sign-up. Every repository is a GitHub template with a live demo and an `AGENTS.md`, so Claude Code, Codex or Cursor can turn it into your site. All of them with live previews: [8b.com/templates](https://8b.com/templates/).
